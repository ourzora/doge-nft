# Engineering notes

Records of substantial changes to this repo, and proposals for changes not yet made.

- `<date>-<topic>.md` — a **record**: what was broken, what was built, what was decided and
  rejected, what is still missing. Written once, after the fact. Not updated as the code moves
  on; the date in the filename is what makes that safe to read later.
- `spec-<topic>.md` — a **proposal**. Describes work that has not been done. Delete it or
  replace it with a dated record once it has.

Keep this in `docs/engineering/` rather than at the top of `docs/`, so there is somewhere
obvious to put site copy later without the two getting mixed up.
